# Simualtion-based-power-analysis
Power analysis

This repository contains simulation-based power analyses for a speech-perception experiment examining whether bimodal exposure produces greater Pre-to-Post improvement than unimodal exposure. The primary analysis uses a binomial generalized linear mixed-effects model at the diagnostic-item level, with participant as a random intercept and diagnostic item as a fixed effect. Power is estimated by repeatedly simulating the planned experimental design and refitting the same Phase × Distribution model at different sample sizes.
